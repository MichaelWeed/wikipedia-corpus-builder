# Security Policy

## Supported Versions

Only the latest active development branch of CorpusSieve receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within CorpusSieve, please do **not** disclose it publicly via public GitHub issues or discussions.

Instead, please report vulnerabilities privately:

1. **GitHub Private Vulnerability Reporting**: Submit a private advisory via GitHub Security Advisories on the repository.
2. **Email**: Contact our security team at `support@intrepid.international`.

Please include:
- A description of the vulnerability and potential impact.
- Steps to reproduce or a proof-of-concept script.
- Any suggested mitigations.

We will acknowledge receipt of your vulnerability report within 48 hours and provide status updates as we work on a fix.
