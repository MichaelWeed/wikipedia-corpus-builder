# AnythingLLM Ingestion Guide

This guide describes how to import RAG-ready Markdown exports generated by CorpusSieve into an AnythingLLM workspace.

## Step 1: Export Corpus to Markdown

Use the `corpussieve export markdown` command to convert your compiled canonical corpus into clean Markdown documents with structured YAML frontmatter:

```bash
corpussieve export markdown --corpus ./output/corpus --output ./exports/markdown
```

This creates a directory containing:
- Individual `.md` files for each extracted article
- `_index.json` document ID lookup map
- `ATTRIBUTION.md` human-readable license attribution
- `attribution.json` machine-readable per-document metadata

## Step 2: Ingest into AnythingLLM Workspace

1. Open **AnythingLLM Desktop** or your web interface.
2. Select your target **Workspace** (or create a new one, e.g. `video-games-knowledge`).
3. Click the **Upload / Move Documents** icon (file folder icon in the workspace header).
4. Drag and drop the `./exports/markdown` directory or click **Upload Folder**.
5. Once processing completes, click **Move to Workspace** and then **Save and Embed**.

## Direct Storage Directory Isolation Notice

Per CorpusSieve design policies:
- CorpusSieve operates purely as a file generator and exporter.
- CorpusSieve **never** directly accesses or mutates AnythingLLM's internal vector database or storage directory.
- All workspace integrations take place cleanly via standard UI uploads or public AnythingLLM API endpoints.
